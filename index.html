📥 Installation

Install Multigravity Pro with a single command on your operating system:

Open your terminal and paste:

bash / zsh 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/shubashbiswas/multigravity-pro/main/install.sh)"

Installs to /usr/local/bin (or ~/.local/bin) and sets up the app icon on macOS.

Open PowerShell (Windows PowerShell 5.1 or PowerShell Core 7+) and paste:

powershell 
irm https://raw.githubusercontent.com/shubashbiswas/multigravity-pro/main/install.ps1 | iex

Installs multigravity.ps1 and multigravity.cmd to %USERPROFILE%\.local\bin and updates your User PATH.

Clone the repository and place the script in any directory on your PATH:

git & terminal 
git clone https://github.com/shubashbiswas/multigravity-pro.git
# macOS / Linux:
cp multigravity-pro/multigravity /usr/local/bin/multigravity && chmod +x /usr/local/bin/multigravity

# Windows:
# Copy multigravity.ps1 to your preferred folder in PATH

Verify Your Installation

Run the built-in diagnostic tool to ensure everything is configured properly:

terminal 
multigravity doctor
Checking multigravity environment...
  [OK] Antigravity: Found at C:\Users\user\AppData\Local\Programs\Antigravity IDE\Antigravity-IDE.exe
  [OK] Global Binary: C:\Users\user\.local\bin\multigravity.cmd
  [OK] Profile storage: C:\Users\user\AntigravityProfiles (writable)

Your environment looks perfect!

🚀 Getting Started

1. Create a Profile

Give your profile a clear name (e.g. work, personal, or a client code):

terminal 
multigravity new work
multigravity new personal

This automatically creates a clickable desktop launcher:

  • macOS: ~/Applications/Multigravity <name>.app
  • Windows: Start Menu shortcut (Multigravity <name>)
  • Linux: ~/.local/share/applications/multigravity-<name>.desktop

2. Launch a Profile

Launch the profile simply by using its name:

terminal 
multigravity work

Forward normal Antigravity parameters through the command line:

terminal 
# Open current folder
multigravity work .

# Open in a new window
multigravity work ~/projects/webapp --new-window

# Open a specific file
multigravity work src/app.ts

3. Enable Shell Tab Completion

Get instant autocomplete for all commands and profile names in your shell:

terminal 
multigravity completion

🪶 Profile Types: Full vs. Auth-Only

In most daily workflows, developers want separate accounts (e.g., Google or GitHub credentials) but don't want to reinstall the same extensions or configure identical editor settings. Auth-only profiles use symlinks to share configuration while keeping login tokens fully isolated.

terminal 
multigravity new client-a --auth-only
multigravity new client-b --auth-only
Feature Full Profile (multigravity new <name>) Auth-Only Profile (--auth-only)
Account / Login Completely isolated sandbox Completely isolated sandbox
Extensions Separate copy in profile Shared via symlink with primary install
Editor Settings & Keybindings Separate copy in profile Shared via symlink with primary install
Disk Footprint ~500 MB+ per profile ~1 – 2 MB per profile (99% savings)
Best Suited For Different tech stacks (e.g. Mobile vs Backend) Multiple accounts with identical setup
Windows Note: Symlink creation in auth-only profiles works best with Windows Developer Mode enabled or PowerShell launched with standard developer privileges.

📋 Profile Templates

Configure a golden environment once (themes, extensions, settings), and stamp out fresh profiles in seconds:

terminal 
# 1. Save an existing configured profile as a blueprint
multigravity template save work python-dev

# 2. View all saved templates
multigravity template list

# 3. Create a brand new profile from that template
multigravity new client-apollo --from python-dev

# 4. Remove a template when finished
multigravity template delete python-dev

📦 Export & Import

Transfer setups between computers, create backups, or share standard team profiles:

terminal 
# Export on macOS / Linux (.tar.gz archive)
multigravity export work ~/Desktop/work.tar.gz

# Export on Windows (.zip archive)
multigravity export work C:\backup\work.zip

# Import (automatically infers profile name from the archive filename)
multigravity import work.tar.gz

# Import with a custom profile name
multigravity import C:\backup\work.zip client-apollo

🔧 Profile Management: Clone, Rename, Delete

Clone an Existing Profile

Duplicate a profile's complete state into a new isolated environment:

multigravity clone work work-backup

Rename a Profile

Safely rename a profile and automatically re-link its desktop/Start Menu shortcut:

multigravity rename work-backup work-v2

Delete a Profile

Remove a profile and its sandboxed data. Multigravity prompts for safety confirmation:

multigravity delete test-profile

Self-Update (update)

Upgrade Multigravity to the newest build directly from GitHub:

multigravity update

multigravity stats Display total storage footprint and installed extension counts per profile.
multigravity clone <src> <dest> Duplicate an existing profile and its launchers.
multigravity rename <old> <new> Rename a profile and update desktop/Start Menu launchers.
multigravity delete <name> Safely delete a profile and its shortcuts (prompts for confirmation).
multigravity template save <prof> <tpl> Save a configured profile as a reusable blueprint.
multigravity template list List all saved profile templates and their sizes.
multigravity template delete <name> Delete a saved template.
multigravity export <name> [path] Export a profile to an archive (.zip on Windows, .tar.gz on Unix).

multigravity completion [shell] Display or generate shell tab completion hooks (bash, zsh, powershell).
multigravity help Show built-in usage and command options.

🏛️ Architecture & File System Layout

Multigravity stores each profile in an independent base directory (defaults to ~/AntigravityProfiles or %USERPROFILE%\AntigravityProfiles).

  • Base Directory: %USERPROFILE%\AntigravityProfiles\<name>
  • User Data: AppData\Roaming\Antigravity & AppData\Roaming\Antigravity IDE
  • Extensions: .antigravity\extensions & .antigravity-ide\extensions (Antigravity IDE 2.0 dual support)
  • Start Menu: %APPDATA%\Microsoft\Windows\Start Menu\Programs\Multigravity <name>.lnk
  • Base Directory: ~/AntigravityProfiles/<name>
  • User Data: Library/Application Support/Antigravity
  • Keychains: Symlinked to ~/Library/Keychains for secure credential storage
  • Extensions: .antigravity/extensions
  • Desktop Launcher: ~/Applications/Multigravity <name>.app
  • Base Directory: ~/AntigravityProfiles/<name>
  • User Data: .config/Antigravity, .cache, .local/share
  • Extensions: .antigravity/extensions
  • Desktop Entry: ~/.local/share/applications/multigravity-<name>.desktop

Environment Variables

Variable Description Default
MULTIGRAVITY_HOME Custom storage directory for all profiles and templates. ~/AntigravityProfiles or %USERPROFILE%\AntigravityProfiles
MULTIGRAVITY_APP Explicit path to the Antigravity or Antigravity IDE executable/app bundle. Auto-detected standard paths
MULTIGRAVITY_PLATFORM Force platform type (darwin, linux). Used for testing. Auto-detected from OS

🛡️ Profile Naming Rules

  • Characters allowed: Letters, numbers, and hyphens (^[a-zA-Z0-9][a-zA-Z0-9-]*$).
  • Must start with an alphanumeric character.
  • Valid: work, client-a, test-10
  • Invalid: -bad, my_profile (no underscores), has spaces

🗑️ Uninstallation Guide

To completely remove Multigravity from your system:

# 1. Remove binary scripts
Remove-Item "$env:USERPROFILE\.local\bin\multigravity.*" -Force

# 2. (Optional) Purge all profiles and templates
Remove-Item -Recurse -Force "$env:USERPROFILE\AntigravityProfiles"

# 3. Clean up Start Menu shortcuts
Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Multigravity *.lnk" | Remove-Item -Force
# 1. Remove binary and icon
sudo rm -f /usr/local/bin/multigravity /usr/local/bin/icon.icns
# Or if installed in ~/.local/bin:
rm -f ~/.local/bin/multigravity ~/.local/bin/icon.icns

# 2. (Optional) Remove profiles data
rm -rf ~/AntigravityProfiles

# 3. Remove launchers
# macOS:
rm -rf ~/Applications/Multigravity\ *.app
# Linux:
rm -f ~/.local/share/applications/multigravity-*.desktop ~/.local/share/multigravity/launchers/*.sh
