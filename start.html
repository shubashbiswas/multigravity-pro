Before we begin

What are these tools?

If you're hearing terms like "IDE", "terminal", and "profiles" for the first time, here's what they mean in plain English.

🤖

Antigravity

A smart notepad for code. You describe what you want to build in plain English, and the AI writes the code. You don't need prior programming experience.

📁

Profile / Workspace

Like user accounts on your smartphone. Each one has its own login, settings, and projects — completely isolated from the others.

🚀

Multigravity

A tool that creates and switches between workspaces. Instead of logging in and out constantly, you run one short command and a separate window opens.

Step-by-Step Setup Guide

Follow each step in order. Each one explains what to do, where to click, and what to verify.

0
Make sure Antigravity is installed

You need the Antigravity IDE on your computer before using Multigravity. If you already have it installed, skip to Step 1. If not, download it from the official Antigravity website and install it like any regular software.

How to verify: Look in your Applications folder (macOS), Start Menu (Windows), or type which antigravity in your terminal (Linux). If found, you are ready to proceed.
1
Open your terminal

A terminalA text window where you type instructions to your computer. Don't worry — you cannot break anything running the commands here. is a text window where you type instructions to your machine.

Press Command ⌘ + Space, type Terminal, and press Enter.

Press the Windows Key, type PowerShell, and press Enter.

Press Ctrl + Alt + T or search for "Terminal" in your application menu.

2
Install Multigravity

Copy the single installation command below, paste it into your terminal, and press Enter:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/shubashbiswas/multigravity-pro/main/install.sh)"
irm https://raw.githubusercontent.com/shubashbiswas/multigravity-pro/main/install.ps1 | iex
Check health: Once installed, verify everything by running: 
multigravity doctor
3
Create your first workspace & launch

Create a named profile (e.g. work) and launch it:

# Create the workspace
multigravity new work

# Launch the workspace
multigravity work
🎉 That's it! Antigravity opens in its own window. Anything you do inside this window (accounts, extensions, settings) stays completely separate from other profiles.

Setup Complete!

Here is what you just accomplished:

  • ✓ Installed Multigravity on your machine
  • ✓ Verified your environment with doctor
  • ✓ Created your first isolated workspace
  • ✓ Launched Antigravity in an independent session
Next Steps

What you can do now

Single-line commands you can type anytime in your terminal:

More Workspaces

Run multigravity new second-project to create another workspace. No limits.

List Workspaces

Run multigravity list to see every workspace you've configured.

Check Status

Run multigravity status to see running instances, last used times, and disk footprints.

Save as Template

Run multigravity template save work my-tpl to reuse a perfected environment.

Auth-Only Workspace

Run multigravity new client --auth-only for a lightweight 2 MB profile with shared settings.

Export & Back up

Run multigravity export work to save a workspace archive to a portable file.

Plain Language Reference

Glossary

Technical terms you might see, explained in plain language.

Terminal A text-based console where you type commands. On Mac/Linux it's called "Terminal", on Windows it's "PowerShell".
IDE "Integrated Development Environment" — a code editor. Think of it as Microsoft Word or Google Docs, but built for code.
Profile A separate, isolated space with its own login, extensions, and settings.
Extension An add-on that gives your editor extra abilities, like apps on your smartphone.
Auth-Only A lightweight profile that isolates logins while sharing extensions via symlinks (~2 MB).
Template A saved blueprint of an environment used to stamp out fresh workspaces.
PATH A list of folders your operating system checks when looking up commands.
